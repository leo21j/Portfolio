# Raw data

**No real complaint data is committed to this repository.** Everything in this
directory is gitignored except `complaints_sample.csv` and this README.

## `complaints_sample.csv` — synthetic, committed

A 120-row fixture generated by
[`scripts/make_sample_data.py`](../../scripts/make_sample_data.py). Every
narrative, company name, and identifier in it was written for this project; none
of it comes from a real complaint, and all ZIP codes are masked.

It exists so the pipeline runs on a fresh clone and so CI can smoke-test it. It
contains 30 distinct narratives repeated across 120 rows, so any model will
memorize it immediately — **it is a plumbing check, not a benchmark.** Do not
report metrics from it.

## `complaints.csv` — real data, not committed

Download the CSV export from the
[CFPB Consumer Complaint Database](https://www.consumerfinance.gov/data-research/consumer-complaints/)
and save it here as `complaints.csv`.

It is excluded from version control for two reasons. The full export is large
enough to be unreasonable in a Git repository, and although CFPB publishes
narratives with consumer consent, each row also carries state, ZIP code, exact
dates, and the company named — enough combined detail that republishing it from
a personal repository is not worth doing.

Note that only a minority of rows have a non-empty
`Consumer complaint narrative`; narratives appear only where the consumer
consented to publication. The pipeline filters to those rows.

## Expected columns

See [`docs/data_dictionary.md`](../../docs/data_dictionary.md) for the full
reference. The loader validates that all of these are present:

```text
Date received                 Tags
Product                       Consumer consent provided?
Sub-product                   Submitted via
Issue                         Date sent to company
Sub-issue                     Company response to consumer
Consumer complaint narrative  Timely response?
Company public response       Consumer disputed?
Company                       Complaint ID
State
ZIP code
```
